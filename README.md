# 試薬作成計算ソフト

ストック試薬の濃度と、作りたい溶液の組成から、**各ストックの添加量と溶媒の目安量**を計算するソフトです。ストックの登録、実験ノート用の表出力にも対応しています。

PCの専用ウィンドウで使えます。ブラウザ版もあり、起動後はインターネット接続やアカウント登録が不要です。

## 2. 起動する

### Windows

ダウンロードした `.exe` をダブルクリックします。インストールは不要です。

### Mac

1. ダウンロードした `.dmg` を開きます。
2. **Reagent Calculator**を **Applications（アプリケーション）** にコピーします。
3. アプリケーションフォルダーから起動します。

警告や「壊れている」という表示が出たら、後半の[困ったとき](#困ったとき)を参照してください。

### ブラウザ版

ZIPを展開し、フォルダー内の **`index.html`** をブラウザで開きます。フォルダー内のほかのファイルも必要なので、`index.html`だけを移動しないでください。

## 3. 溶液の組成を計算する

1. **作成する溶液**に、溶液名・最終容量・容量の単位・溶媒名を入力します。
2. **ストックと最終組成**に、試薬名・ストック濃度・その単位を入力します。
3. 作りたい**最終濃度・その単位**を入力します。試薬を増やす場合は「＋ 試薬を追加」を押します。
4. **必要量を計算**を押します。各ストックの添加量と、溶媒の目安量が表示されます。

### 入力例：バッファーを100 mL作る

最終容量を **100 mL**、溶媒名を **精製水**にし、次の組成を入力します。初回起動時もこの例が表示されます。

| 試薬名 | ストック濃度 | 作りたい最終濃度 | 計算結果：添加量 |
| --- | --- | --- | --- |
| Tris-HCl | 1 M | 50 mM | 5 mL |
| NaCl | 5 M | 150 mM | 3 mL |

溶媒の目安量は **92 mL**です。実際の調製では、両方のストックを加えてから、精製水で**最終容量100 mLに定容**してください。

**溶媒量は目安です。** 混合後の体積が単純な足し算にならない場合もあるため、表示された溶媒量を加えるだけで最終容量になるとは限りません。

## 4. よく使うストックを登録する

1. **保存したストック試薬**に、名前・濃度・単位を入力します。
2. **ストックを登録**を押します。
3. 次回から、一覧の **＋ 試薬名（濃度）** をクリックすると、組成に追加できます。
4. 追加した行の**最終濃度**を入力して計算します。

同じ名前でも濃度が異なれば別々に登録できます。同じ名前・濃度・単位の重複は登録しません。登録上限は200件です。

## 5. 実験ノートに貼る・印刷する

計算後に、目的に合うボタンを選びます。表には、溶液名・最終容量と、試薬名・ストック濃度・最終濃度・添加量を出力します。

| やりたいこと | ボタン | 次の操作 |
| --- | --- | --- |
| Wordや電子実験ノートに貼る | **表をコピー** | 貼り付け先でペーストします。表に対応しないアプリでは文字列になります。 |
| 紙の実験ノートに貼る | **表を印刷** | 印刷設定の倍率で大きさを調整します。入力画面は印刷されません。 |
| PDFとして残す | **PDF保存** | 専用ウィンドウ版は保存先を選択。ブラウザ版は印刷画面で「PDFに保存」を選択します。 |
| 表だけをファイルにする | **表をHTML保存** | 保存したファイルをブラウザで開き、コピーや印刷をします。 |

表のコピーができない場合は、**表をHTML保存**を利用してください。

## 6. 保存する・別のPCへ移す

入力はアプリ／ブラウザに自動保存されます。重要な内容は、ファイルにも保存してください。

**調製中の入力とストック一覧は、別々に保存します。**

| 保存したい内容 | 保存するボタン | 復元するボタン |
| --- | --- | --- |
| 作成する溶液・組成の入力 | **入力をファイルに保存** | **保存した入力を開く** |
| 登録したストック一覧 | **ストック一覧を保存** | **ストック一覧を開く** |

保存されるJSONファイルは、対応する「開く」ボタンから読み込みます。ストック一覧を開くと既存の登録に追加され、同じ登録は重複しません。

別PCに移すときは、両方のファイルを移してください。ブラウザ版と専用ウィンドウ版の保存内容は別です。保存領域を消去すると自動保存されたデータも失われます。

## 使える単位・計算の範囲

| 種類 | 対応単位 |
| --- | --- |
| モル濃度 | M、mM、µM |
| 質量濃度 | mg/mL、g/L、µg/mL、% (w/v) |
| 体積百分率 | % (v/v) |
| 倍率 | ×（10×ストックから1×など） |
| 最終容量 | L、mL、µL |

濃度は**同じ種類の単位同士**で換算できます。例えば1 Mから50 mMは計算できますが、分子量が必要なMからmg/mLへの変換はできません。

固体の秤量、pH調整、試薬の安全性・混合適合性の判断には対応していません。混合順序や溶解性は別途確認してください。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 最終濃度がストック濃度を超えている | ストック濃度・最終濃度・単位を確認します。必要なら、より濃いストックを使います。 |
| ストック量の合計が最終容量を超えている | 組成と単位を見直します。 |
| 濃度単位の種類が合わない | モル濃度同士、質量濃度同士など、同じ種類を選びます。 |
| コピーした表が崩れる | 「表をHTML保存」からコピーするか、PDF出力を使います。 |
| 自動保存できない | 「入力をファイルに保存」で保存します。ストック登録には保存可能なブラウザ／専用ウィンドウ版を使ってください。 |
| Macで起動できない | OSのバージョンとIntel／Apple Siliconの選択を確認します。下の案内も参照してください。 |

### 起動時に発行元の警告が出る

現在の配布版は、Windowsの発行元署名とMacのApple Developer ID署名・公証を設定していないため、警告や起動制限が出る場合があります。公式リリースから取得したファイルか確認してください。管理PCの場合は管理者に相談してください。

<details>
<summary><strong>Macで「壊れているため開けません」と出る場合の手順</strong></summary>

ダウンロードしたアプリに対するMacの保護機能によって、この表示が出ることがあります。表示だけでは、実際のファイル破損か、起動制限かは判断できません。

まず公式Releaseから対応するDMGを再取得し、Applicationsにコピーした後に起動してください。問題が続く場合、公式配布元を信頼できることを確認したうえで、ターミナルで次を実行できます。

```sh
codesign --verify --deep --strict --verbose=2 "/Applications/Reagent Calculator.app"
```

**署名検証にエラーが出たら、この先の操作は行わず、再ダウンロードまたは不具合報告をしてください。** 検証が成功しても同じ表示が出る場合に限り、次の操作でこのアプリの検疫属性を解除して起動できます。この操作はこのアプリに対するダウンロード検疫のチェックを外すもので、公証や発行元の保証を追加するものではありません。

```sh
xattr -dr com.apple.quarantine "/Applications/Reagent Calculator.app"
open "/Applications/Reagent Calculator.app"
```

PC全体のGatekeeperを無効にする必要はありません。管理PCの場合は管理者に相談してください。この操作を避けたい場合はオフラインブラウザ版を利用できます。


</details>
