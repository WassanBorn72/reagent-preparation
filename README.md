# 試薬作成計算ソフト

ストック試薬の濃度と、作りたい溶液の組成を入力すると、必要なストック量と溶媒量を計算できます。PCの専用ウィンドウ、またはブラウザで使えます。起動後はオフラインで動作し、アカウント登録は不要です。

## ダウンロード

[リリース一覧](https://github.com/WassanBorn72/reagent-preparation/releases)を開き、利用するPCに合うファイルを **Assets** からダウンロードしてください。バージョン番号はリリースごとに異なります。

| 利用するPC | ファイル名の末尾 | 使い方 |
| --- | --- | --- |
| Windows（x64） | `Windows-x64-Portable.exe` | ダウンロードしたEXEをダブルクリック |
| Intel Mac | `macOS-x64.dmg` | DMGを開き、アプリをApplicationsにコピーして起動 |
| Apple Silicon Mac（Mシリーズ） | `macOS-arm64.dmg` | DMGを開き、アプリをApplicationsにコピーして起動 |
| ブラウザで使う場合 | `Browser-Offline.zip` | ZIPを展開し、フォルダー内の `index.html` を開く |

ファイル名は `Reagent-Preparation-Calculator-vバージョン番号-…` です。通常の利用には **Source code (zip / tar.gz)** を選ぶ必要はありません。追加の開発ツールのインストールも不要です。

Macの種類はAppleメニューの「このMacについて」で確認できます。「チップ：Apple M…」ならApple Silicon版、「プロセッサ：Intel…」ならIntel版を選んでください。

### Macの対応OS

**v1.1.3はmacOS 12（Monterey）以降を対象**としています。macOS 12.7.4では、v1.1.0・v1.1.1は起動できないため、v1.1.3の対応版を選んでください。macOS 12.7.4での実機起動はまだ確認できていません。

### 起動時に警告が表示される場合

現在の配布版は署名・Macの公証を設定していないため、WindowsやMacで発行元に関する警告や起動制限が出る場合があります。公式のリリースページから取得したファイルか確認してください。管理されたPCでは管理者に相談してください。

ブラウザ版では、展開したフォルダー内の `index.html`、`app.js`、`calculator.js`、`style.css` を同じ場所に置いたまま使ってください。

## 溶液を作るための計算

1. 作成する溶液の名前、最終容量、容量の単位、溶媒名を入力します。
2. 「＋ 試薬を追加」で、ストック試薬の名前・濃度・単位を入力します。
3. 各試薬の最終濃度・単位を入力します。
4. 「必要量を計算」を押すと、各ストックの添加量と溶媒の目安量が表示されます。

画面には最初から次の例が入力されています。

**例：50 mM Tris-HCl・150 mM NaClを100 mL作る**

| 試薬 | ストック濃度 | 最終濃度 | 添加量 |
| --- | --- | --- | --- |
| Tris-HCl | 1 M | 50 mM | 5 mL |
| NaCl | 5 M | 150 mM | 3 mL |
| 精製水 | — | — | 約92 mL（100 mLに定容） |

各ストックを加え、精製水で最終容量100 mLに定容してください。溶媒量は体積加算を仮定した目安です。

## ストック試薬を記録して追加

1. 「保存したストック試薬」で名前・濃度・単位を入力し、「ストックを登録」を押します。
2. 登録済み試薬の「＋ 名前（濃度）」をクリックすると、組成の行が追加されます。
3. 追加した行に最終濃度を入力して計算します。

同じ名前でも濃度や単位が異なるストックは別に登録できます。同じ名前・濃度・単位の重複登録は防ぎます。登録はアプリ／ブラウザの保存領域に保持されます。保存領域を消去すると一覧も失われるため、「ストック一覧を保存」でJSONバックアップしてください。「ストック一覧を開く」は既存一覧へ追加し、同じ登録は重複させません。最大200件です。調製レシピの入力JSONとストック一覧JSONは別のファイルです。

## 実験ノート用の組成表

計算後、試薬名・ストック濃度・最終濃度・添加量と、溶液名・最終容量を出力できます。

- **表をコピー**：HTMLの表とテキストをコピーします。Wordや表に対応した実験ノートに貼り付けてください。貼り付け先によってはテキストになります。
- **表をHTML保存**：表だけを独立したファイルとして保存します。ブラウザで開き、コピー・印刷できます。
- **表を印刷**：入力画面やストック一覧を除いた、罫線付きのレシピを印刷します。実験ノートに貼れるよう印刷設定の倍率でサイズを調整してください。
- **PDF保存**：デスクトップ版では保存先を選択してPDFを書き出します。ブラウザ版では印刷画面から「PDFに保存」を選択してください。

コピー権限が得られないブラウザではHTML保存をご利用ください。表の溶媒量は目安なので、記載された最終容量に定容してください。

## 対応単位と制約

- モル濃度：M、mM、µM
- 質量濃度：mg/mL、g/L、µg/mL、% (w/v)
- 体積百分率：% (v/v)
- 倍率：×（10×ストックから1×を作る場合など）

同じ種類の単位のみ換算できます。分子量を必要とするモル濃度と質量濃度の変換、固体からの秤量、pH調整には対応していません。ストック量は C₁V₁ = C₂V₂ に基づきます。溶媒量は体積加算の近似なので、実際は溶媒で最終容量に定容してください。表示値は有効数字6桁です。混合順序や試薬の適合性・安全性を判定する機能はありません。

## 入力の保存・別のPCへの移行

調製中の入力はアプリまたはブラウザに自動保存されます。「入力をファイルに保存」で調製入力をJSONファイルとして保存し、「保存した入力を開く」で復元できます。

ストック一覧は別に保存します。「ストック一覧を保存」と「ストック一覧を開く」を使ってください。別PCへ移行する際は、調製入力とストック一覧の両方をバックアップします。

ブラウザ版と専用ウィンドウ版の保存内容は別です。保存領域を消去すると入力も失われるため、重要なデータはファイルに保存してください。ブラウザ版で自動保存できない場合も、入力のファイル保存をご利用ください。

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 最終濃度がストック濃度を超えている | より濃いストックを使うか、最終濃度を見直してください。 |
| ストック量の合計が最終容量を超えている | 各試薬の濃度・単位と、必要な組成を見直してください。 |
| 濃度単位の種類が合わない | モル濃度同士、質量濃度同士など、同じ種類を選んでください。 |
| コピーした表が文字列になる | 貼り付け先の表対応を確認するか、「表をHTML保存」を利用してください。 |
| Macで起動できない | OSのバージョンと、Intel／Apple Siliconの選択を確認してください。 |

解決しない場合は[不具合報告（Issues）](https://github.com/WassanBorn72/reagent-preparation/issues)へ、ソフトのバージョン、OS、操作手順、表示されたエラーを記載してください。試薬名など非公開情報が含まれる場合は伏せてください。
